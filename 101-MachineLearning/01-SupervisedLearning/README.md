# ML Exercise 01

To run locally:

1. Run `git clone https://github.com/sakisv/msc_dws.git` to clone this repo
1. Install the latest version of `uv` following the instructions from here: https://docs.astral.sh/uv/getting-started/installation/
1. Switch into this directory
1. Run `uv run jupyter lab`

This last command will install all the dependencies in a virtual environment, start the
jupyter server and open a new tab in your default browser and point it to the notebook.
